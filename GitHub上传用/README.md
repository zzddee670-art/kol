# KOL 红人邮件系统

一个给别人发合作邀约邮件的小系统。导入红人名单 → 系统按国家/博主类型/语种/平台自动挑对模板 → 一键发送。

**一个人一封邮件逐封发送**，红人看不到其他人的邮箱。系统不是密送（BCC）：每封邮件只有一个收件人。

---

## 🟢 新手使用指南（给第一次拿到这个项目的人）

> 不用装任何软件、不用管理员权限、不用懂代码。**全程只需 4 步。**

### 第 1 步：下载整个项目

打开本项目的 GitHub 页面，点击绿色的 **Code** 按钮 → 选 **Download ZIP**。

⚠️ 不要只下载某个文件，必须下载整个 ZIP 压缩包。

### 第 2 步：解压

把下载好的 ZIP 文件**全部解压**出来（右键 → 全部解压缩 → 提取/解压缩）。不要在 ZIP 压缩包里面直接运行程序。

解压完成后，打开解压出来的 `kol-main` 文件夹，再进入里面的 `GitHub上传用` 文件夹。确认地址栏里不再显示 `kol-main.zip`。

在 `GitHub上传用` 文件夹中，应该能看到这些文件和文件夹：

```
打开KOL系统.bat     ← 就是它，一会儿双击它
start.bat
start.sh
runtime/            ← 必须有，少了就跑不起来
server/
web/
data/
...
```

### 第 3 步：运行

在已经解压的 `GitHub上传用` 文件夹里，双击 **`打开KOL系统.bat`**。

- 会弹出一个黑色窗口（命令行），不用管它，让它开着。
- 几秒后浏览器会自动打开系统页面（地址是 `http://localhost:8787`）。
- 如果浏览器没自动打开，手动复制 `http://localhost:8787` 到浏览器地址栏。

### 遇到弹窗时怎么选

- 如果 Windows 提示“压缩(zipped)文件夹”需要先提取文件，并显示“全部解压缩 / 运行 / 取消”：选 **“全部解压缩”**，不要选“运行”。解压后再到普通文件夹里双击 bat。
- 如果出现“Windows 已保护你的电脑”：先确认项目是从本 README 对应的 GitHub 仓库下载的。确认来源可信并且愿意运行时，才选择“更多信息”→“仍要运行”；不确定就选“取消”。
- 如果出现“是否允许此应用对你的设备进行更改”：本程序不需要管理员权限，选 **“否”**。
- 如果弹出 **“Windows 安全中心 — 是否要允许公共网络、专用网络、域网络访问此应用？”**（发布者是 Python Software Foundation）：这是防火墙询问。本系统需要联网发送邮件，选 **“允许”**。工具只在本机 localhost 运行，不会对外暴露服务，可以放心允许。
- 如果弹窗标题是“Python”或内容有 `Python`、`error`、`找不到`：这是程序报错，不是权限询问。不要猜着点允许；记下标题和错误文字，再联系提供项目的人。

### 第 4 步：使用

系统打开后：
1. 先在「设置」里填你的发件邮箱和 SMTP 授权码（Gmail 用 16 位应用专用密码）。
2. 在「红人名单」里导入你的 Excel/CSV 名单。
3. 系统会自动给每个红人匹配最合适的邮件模板。
4. 点「发送」，一封一封发出去。

### 怎么关闭 / 下次怎么再打开

- **关闭**：直接关掉那个黑色命令行窗口就行。
- **下次再用**：再次双击 `打开KOL系统.bat`。

### ❓ 常见问题

**Q：双击 bat 没反应 / 一闪而过？**
A：确认解压出来的文件夹里有 `runtime\python\python.exe`。如果没有，说明你只下载了部分文件，重新下载整个 ZIP。

**Q：黑色窗口报错说找不到 runtime？**
A：`打开KOL系统.bat` 必须和 `runtime`、`server`、`web` 这些文件夹**在同一个目录里**。不要把 bat 单独拿出来。

**Q：别人能用 `http://localhost:8787` 打开吗？**
A：不能。`localhost` 只代表运行程序的这台电脑。其他人要通过公网网址使用，需要另外部署到支持 Python 后端的云平台；GitHub 只存放项目文件，不会替你运行 bat。

**Q：Mac / Linux 能用吗？**
A：可以，但需要自己装 Python 3.10+，然后在终端运行：
```bash
python3 server/app.py
```

## 特点

- **零依赖**：只用 Python 标准库，不用 `pip install` 任何东西。
- **跨平台**：Windows / macOS / Linux 都能跑，浏览器打开就能用。
- **沿用原版界面**：中文页签、顶部统计卡片、右侧发送操作与邮件预览。
- **能上云**：部署到云平台就是一个公开网址，评委/同事点开就能用，不用装任何软件。
- **会挑模板**：同一批名单里，日本复古数码博主收日语邮件，德国博主要德语邮件，系统自己匹配。

## 一、在自己电脑上打开

Windows 版本已经附带便携 Python，不需要安装软件或管理员权限：

- Windows：双击 `打开KOL系统.bat`（或 `start.bat`）
- macOS / Linux：需要 Python 3.10 以上，然后运行：
  ```bash
  python3 server/app.py
  ```

## 二、名单表格怎么填

Excel / CSV 第一行写表头：

```text
姓名,邮箱,主页链接,平台,备注,物料单号,视频标题
```

认识的列名：

- 姓名：`name`、`姓名`、`红人姓名`
- 邮箱：`email`、`邮箱`
- 主页链接：`profileUrl`、`profile_url`、`主页链接`
- 平台：`platform`、`平台`
- 备注：`note`、`备注`

想加多少列都行（`国家`、`博主类型`、`语种`、`优惠码`……）。第一行写什么列名，模板里就能用对应占位符。
即使列名不叫"邮箱"，只要单元格里有 `alice@example.com` 这类邮箱，系统也会尽量认出来。

## 三、邮件模板

用 `{{name}}` 表示红人姓名，发送前自动替换。可以加粗：`**这段话会加粗**`。

```text
{{name}} 您好，

我很喜欢你最近的 {{视频标题}}。
这次合作的物料单号是 {{物料单号}}。

我们想和您聊一下产品合作。
```

如果邮件里还剩没替换的 `{{xxx}}`，系统会**拦截这一封**，不会发出去。

模板库存在 `data/state.json` 的 `templates` 里，每条模板可以带 `country` / `creatorType` / `language` / `platform` 四个匹配条件，系统按权重（博主类型 5 > 国家 3 > 语种 2 > 平台 1）打分挑最合适的一条。

## 四、安全设计

- 发件账号、授权码**不写进文件**，每次打开重新填，避免密码留在磁盘上。
- 强制**一封邮件只有一个收件人**，不允许抄送/密送，防止红人互相看到。
- 发送前自检：收件邮箱为空、邮箱里写了多个地址、标题为空、正文为空、正文变成乱码，都会拦截并写进日志。
- 有每日发送上限和每封之间的间隔，避免被判定为垃圾邮件。
